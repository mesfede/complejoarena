# Iconos Personalizados para Complejo Arena

Puedes colocar aquí tus imágenes/iconos en formato **PNG transparente** (recomendado 128x128px o 256x256px, fondo transparente):

- `canchas.png` -> Para la tarjeta de Alquiler de Canchas
- `cumpleanos.png` -> Para la tarjeta de Festejá tu Cumple
- `torneos.png` -> Para la tarjeta de Torneos y Ligas
- `escuelitas.png` -> Para la tarjeta de Escuelitas Deportivas

La aplicación detectará y usará automáticamente tus archivos PNG en cuanto los subas a esta carpeta.
